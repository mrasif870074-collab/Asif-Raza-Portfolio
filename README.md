# Asif Raza — AI Engineer Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation and current year
- `images/` — add your profile/project images here

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Customize
1. Replace the `AR` profile placeholder with your photo.
2. Update project GitHub links to each repository's direct URL.
3. Add future AI/ML projects and certificates.
4. Add your resume link if you have a PDF.
